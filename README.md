# Задание 1

### Общее описание задания (Вариант 7)

Разработать консольное приложение с дружественным интерфейсом и возможностью выбора заданий для работы с базой данных «Рекламное агентство» из файла **LR5-var7.xls**. База данных состоит из четырёх связанных таблиц:

* **Клиенты** — код клиента (первичный ключ), фамилия, имя, отчество, место жительства;
* **Заказы** — код заказа (первичный ключ), код клиента, код услуги, дата заказа, количество;
* **Услуги** — код услуги (первичный ключ), код типа услуги, название услуги, стоимость услуги;
* **Типы услуг** — код типа услуги (первичный ключ), название.

Все элементы базы данных представлены объектами классов предметной области (с конструкторами, свойствами с валидацией и переопределённым методом `ToString()`), а весь функционал реализован во вспомогательном классе `DatabaseManager` с применением LINQ-запросов и обработкой возможных ошибок.

### Описание классов предметной области

| `Order` | `OrderId` (`int`), `ClientId` (`int`), `OrderDate` (`DateOnly`), `ServiceId` (`int`), `Count` (`int`) | Конструктор по умолчанию (единицы и текущая дата) и параметризованный конструктор. | `Service` | `ServiceId` (`int`), `TypeId` (`int`), `Name` (`string`), `Price` (`int`) | Конструктор по умолчанию (`1`, `1`, `"Не задано"`, `0`) и параметризованный конструктор. | `TypeService` | `TypeId` (`int`), `Name` (`string`) | Конструктор по умолчанию (`1`, `"Не задано"`) и параметризованный конструктор. Проверка: `TypeId > 0`, название не может быть пустым. | Возвращает строку с ID и названием типа услуги. |

В файле `Program.cs` реализовано консольное меню с циклами навигации, методами безопасного ввода чисел и дат (`TryReadInt`, `TryReadDate`) и глобальной обработкой исключений (`FileNotFoundException`, `IOException`, `Exception`).

## Задача 1. Чтение базы данных из Excel файла

### Текст задачи

Реализовать чтение базы данных из Excel-файла `LR5-var7.xls` с заполнением коллекций объектов соответствующих классов и обработкой возможных ошибок.

### Алгоритм решения

1. При запуске программы в `Program.cs` вызывается метод `TryInitialLoad()`, который проверяет наличие файла `LR5-var7.xls` в рабочей директории и при его наличии автоматически создаёт экземпляр `DatabaseManager`.
2. Пользователь также может вручную загрузить базу данных через пункт `1` главного меню (`HandleLoadDatabase()`), введя путь к файлу или нажав `Enter` для использования пути по умолчанию.
3. Конструктор `DatabaseManager(string filePath)` валидирует путь к файлу, инициализирует списки и вызывает метод `LoadFromExcel()`, который работает следующим образом:
   * проверяет существование файла через `File.Exists(FilePath)` и выбрасывает `FileNotFoundException`, если файл отсутствует;
   * очищает текущие коллекции `_clients`, `_orders`, `_services` и `_typeServices`;
   * открывает файловый поток `FileStream` на чтение и загружает книгу Excel с помощью `WorkbookFactory.Create(fs)` из библиотеки `NPOI`;
   * последовательно считывает листы `"Клиенты"`, `"Заказы"`, `"Услуги"` и `"Типы услуг"`, начиная со строки с индексом `1` (пропуская заголовки и пустые строки);
   * при чтении листа `"Заказы"` преобразует числовое представление даты Excel через `DateUtil.GetJavaDate(...)` в структуру `DateOnly` и формирует объекты `Order` (ячейки: код заказа, код клиента, дата заказа, код услуги, количество);
   * для остальных листов считывает числовые и строковые значения ячеек и добавляет созданные объекты в соответствующие списки.
4. При отсутствии файла или его блокировке программой Excel исключения перехватываются в блоке `try-catch` метода `Main`, выводя понятное сообщение пользователю.

## Задача 3. Удаление элементов (по ключу)

### Текст задачи

Реализовать удаление элементов базы данных по первичному ключу с помощью LINQ-запросов и с обработкой возможных ошибок.

### Алгоритм решения

1. При выборе пункта `3` главного меню запускается метод `HandleDelete(db)`: пользователю предлагается выбрать номер таблицы (`1`–`4`) и ввести целочисленный `ID` удаляемой записи с проверкой корректности ввода через `TryReadInt`.
2. Введённые параметры передаются в метод `DatabaseManager.DeleteByKey(int tableNumber, int id)`, который выполняет следующие шаги:
   * фиксирует общее число записей во всех четырёх таблицах до удаления (`countBefore`);
   * в зависимости от `tableNumber` с помощью LINQ-запроса (`from ... where ... != id select ...`) формирует новый список для выбранной таблицы без удаляемой записи (при неверном номере таблицы выбрасывается `ArgumentException`);
   * для поддержания ссылочной целостности выполняет каскадное удаление связанных записей с помощью LINQ `join`: в `_services` остаются только услуги, чей `TypeId` присутствует в `_typeServices`, а в `_orders` — только заказы, чьи `ClientId` и `ServiceId` присутствуют в актуальных `_clients` и `_services`;
   * сравнивает итоговое количество записей `countAfter` с `countBefore` и возвращает `true`, если хотя бы одна запись была удалена.
3. В консоль выводится сообщение об успешном удалении записи вместе со связанными данными либо о том, что запись с указанным ID не найдена.

## Задача 5. Реализация 4 LINQ-запросов

### Текст задачи

Сформулировать и реализовать 4 запроса к базе данных с использованием LINQ:

1. 1 запрос с обращением к одной таблице;
2. 1 запрос с обращением к двум таблицам;
3. 2 запроса с обращением к трём таблицам.

При этом 2 запроса должны возвращать перечень значений, а 2 запроса — одно значение.

### Алгоритм решения

При выборе пункта `5` главного меню запускается цикл подменю `HandleQueriesMenu(db)`, позволяющий запускать любой из четырёх запросов или вернуться в главное меню (`0`). Все запросы реализованы методами класса `DatabaseManager`:

* **Запрос 1 (1 таблица, возвращает перечень) — метод `GetMidPriceServices()`**
  * *Формулировка*: Вывести перечень услуг стоимостью от 5 000 до 25 000 руб. включительно, отсортированный по убыванию цены, а при совпадении цены — по возрастанию названия.
  * *Алгоритм*: Обращается к коллекции `_services`, фильтрует элементы условием `where s.Price >= 5000 && s.Price <= 25000`, выполняет многоуровневую сортировку `orderby s.Price descending, s.Name ascending` и возвращает `List<Service>`.
* **Запрос 2 (2 таблицы, возвращает перечень) — метод `GetOutdoorAndInternetServices()`**
  * *Формулировка*: Вывести перечень услуг категорий «Наружняя реклама» и «Интернет-маркетинг» с указанием категории, названия и стоимости, отсортированный по названию категории и возрастанию цены.
  * *Алгоритм*: Объединяет `_services` и `_typeServices` по `TypeId` через `join`, фильтрует по `t.Name == "Наружняя реклама" || t.Name == "Интернет-маркетинг"`, сортирует по `t.Name ascending, s.Price ascending`, проецирует результат в форматированные строки `$"{t.Name}: «{s.Name}» — {s.Price} руб."` и возвращает `List<string>`.
* **Запрос 3 (3 таблицы, возвращает одно значение) — метод `GetTopMoscowClient()`**
  * *Формулировка*: Определить клиента из г. Москва, оформившего самый дорогой заказ (по произведению количества на стоимость услуги), и вывести его фамилию, имя, номер заказа и итоговую сумму.
  * *Алгоритм*: Соединяет `_orders`, `_clients` (по `ClientId == Id`) и `_services` (по `ServiceId`), фильтрует клиентов с `c.City == "г. Москва"`, сортирует заказы по убыванию стоимости `o.Count * s.Price descending` и извлекает первый результат через `FirstOrDefault()`. Если таких заказов нет, возвращается строка `"Заказы клиентов из г. Москва не найдены."`.
* **Запрос 4 (3 таблицы, возвращает одно значение) — метод `GetJulyPolygraphyUnitsCount()`**
  * *Формулировка*: Определить суммарное количество заказанных единиц услуг типа «Полиграфия» за июль 2018 года.
  * *Алгоритм*: Соединяет `_orders`, `_services` и `_typeServices`, отбирает записи, удовлетворяющие условию `t.Name == "Полиграфия" && o.OrderDate.Month == 7 && o.OrderDate.Year == 2018`, выбирает значения `o.Count` и вычисляет итоговую сумму с помощью метода расширения `.Sum()`.

## Задача 6. Сохранение изменений в Excel файл

### Текст задачи

Реализовать сохранение всех внесённых изменений обратно в Excel-файл с обработкой возможных ошибок.

### Алгоритм решения

1. При выборе пункта `6` главного меню после проверки `EnsureLoaded(db)` вызывается метод `db.SaveToExcel()`.
2. В методе `SaveToExcel()` создаётся новая книга формата `.xls` (`new HSSFWorkbook()`) и настраивается стиль ячейки для форматирования дат `"dd.MM.yyyy"`.
3. Последовательно создаются четыре листа (`"Клиенты"`, `"Заказы"`, `"Услуги"`, `"Типы услуг"`): в нулевую строку каждого листа записываются заголовки столбцов, а в последующие строки — актуальные данные из списков `_clients`, `_orders`, `_services` и `_typeServices`. Для дат заказов выполняется преобразование `DateOnly` в `DateTime` с применением настроенного стиля `dateStyle`.
4. Книга записывается на диск по пути `FilePath` через `FileStream` в режиме `FileMode.Create` с доступом `FileAccess.Write`.
5. Если файл в момент сохранения открыт в Microsoft Excel, блок `catch (IOException)` в `Program.cs` перехватывает ошибку и выводит предупреждение о необходимости закрыть таблицу.
